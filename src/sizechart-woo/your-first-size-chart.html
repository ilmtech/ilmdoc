Click Add Size Chart, or the title of an existing chart. The edit screen has four tabs. Fullscreen hides the WordPress admin menus to give the designer more room. Click Save (back to the list) or Save and stay when you are done.

Step by step

  1. In WordPress admin, open the ILM Size Chart menu. This is the list of your size charts. Click Add Size Chart.

  2. The form opens on the General tab. Give the chart a name. Only you see it, in the list. We call it Men's T-shirts.

  3. Show in: Popup puts a button on the product page that opens the chart in a window. Page shows the chart directly on the page. We keep Popup.

  4. The status is Enabled, so the chart is shown in the shop as soon as you save it.

  5. Now open the Sizechart Designer tab. A new chart is empty.

  6. Click Add Row. A row holds one or more columns, and every column shows one component.

  7. Click to add component. Choose what this place shows: a table, text, an image, a video, tabs or another web page.

  8. We choose Table. The table editor opens with a small sample: the sizes in the first row and one measurement in every row below.

  9. The plus buttons add a column or a row, the minus buttons remove one. We add a column for size XL.

  10. Then type the values: XL, chest 42 inches, waist 36 inches. Every cell is a plain text box.

  11. Click Save in the editor. The table is now in the designer, exactly as the shopper will see it, with an inch and centimetre switch above it.

  12. Last, the Display Rule tab: it decides on which products the chart is shown. We start with Products.

  13. Set Enable Products Rule to Yes, and Show Sizechart to: Selected Products.

  14. Search the product by its name or SKU, and click the search button.

  15. Click the T-shirt in the results. It moves to the list of selected products.

  16. Click Save and stay. The chart is saved and active.

  17. Now the shop. We search for the Hummingbird printed T-shirt and open it. The Size Chart button is on the product page. The Find my size button next to it is a Pro feature with its own video.

  18. The shopper clicks it, and the chart opens in a window.

  19. With CM, every measurement is converted to centimetres. IN switches back.

  20. The cross closes the window. The next videos show every setting of the button, the window and the designer.
