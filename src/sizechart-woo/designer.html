The designer builds the chart itself. A chart is made of rows; each row has one or more columns, and each column holds components. What you see in the designer is what the shopper sees.

Toolbar buttonWhat it does
Undo / RedoTakes back the last change, or does it again.
ThemesReady-made looks for the chart (see Themes).
Add RowAdds an empty row at the end of the chart.
Export / ImportSaves the design as a file, or loads a design file — to copy a chart to another chart or shop.

Point at a row or a column to see its tools: drag it to another place, open its settings (spacing, background, border, shadow, column width), or delete it; a column can also be duplicated or hidden. Deleting asks first when the row or column holds components, and a row always keeps at least one column.

Components

Click Click to add component in an empty column, or Add Component in a column's menu, and pick a type:

ComponentUse it for
TableThe size table itself, with an optional unit switch.
TabSeveral panels behind tab titles, e.g. Sizes, How to measure, Fit and care. Each tab holds its own components.
ImageA picture, such as a measuring guide. Upload it or pick one from the image library.
VideoA YouTube video, e.g. on how to measure.
Text EditorFormatted text, such as measuring tips.

Click a component to edit it. Every component has a Style tab (spacing, background, border, shadow) and an Advanced tab (your own ID, class and CSS).
