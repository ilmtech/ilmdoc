StatusEnable shows the chart in the shop; Disable keeps it without showing it.
PriorityWhen several size charts match a product, the one with the highest priority is shown.

Which chart does a product show? When several charts match a product, the chart with the highest Priority (General tab) is shown. When two charts have the same priority, a chart that lists the product (or its feature, category, brand or supplier) beats a chart set to All, in this order: product, feature, category, brand, supplier.
