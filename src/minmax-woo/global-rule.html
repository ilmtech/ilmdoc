LevelWhat it does
Global RuleOne rule for the whole shop, used when nothing more specific matches.

Apply Rule to Individual Products (shown for Category / Brand / Tag / User Role / Global): Enable checks the limit separately for each product under that rule; Disable pools every product under the rule into one shared total.

Step by step

  1. The Global rule is set right on the Configuration tab, with the global value of each limit.

  2. Type two in the global value of Minimum Quantity. Every product now has a minimum of two.

  3. The Mountain fox notebook has no rule of its own, so it shows minimum order two.

  4. The Brown bear notebook has its own product rule, a minimum of five. A more specific rule always comes before the global one.

  5. Now a minimum order value. We set the global minimum back to zero, and enable Minimum Amount.

  6. Its global value is thirty dollars.

  7. Further down, on the Global Rule card, disable Apply Rule to Individual Products. The whole cart is added up, so this is a minimum order value of thirty dollars.

  8. A customer adds two notebooks, twenty five dollars eighty,

  9. and the cart asks them to spend at least thirty dollars in total. Checkout refuses the order until it reaches thirty dollars.
