SettingWhat it does
Allowed QuantitiesAdds the Allowed Qty column. Its Global value (e.g. 6,12,24) is the Global rule's value, used like the other Global values when no more specific rule matches.
Allowed QtyThe only quantities that can be ordered, separated by commas, e.g. 6,12,24. A quantity in between is rounded up to the next allowed one when it is added to the cart. A rule takes either Allowed Qty or Multiple Qty, not both.

Step by step

  1. On the Configuration tab, Allowed Quantities is enabled, so the rule table has an Allowed Qty column.

  2. Take the Customizable mug. Search for it.

  3. Type the quantities, separated by commas: six, twelve, twenty four. A rule uses either Allowed Qty or Multiple Qty, not both.

  4. The product page lists the quantities the customer can order, and the box starts at six.

  5. Let us try a quantity in between, eight.

  6. The cart lists the allowed quantities, and checkout stays locked until the quantity is one of them.

  7. Twelve is on the list, so the message is gone.

  8. The global value on the card is the allowed list for products with no rule of their own.
