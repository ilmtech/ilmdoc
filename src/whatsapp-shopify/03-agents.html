Agents

3.1 Add an agent

Open the Chat widget page and find the Agents section. Click Add agent. Add the person or team number shoppers should reach on WhatsApp.

  1. Enter a Name and a Role.
  2. Enter the WhatsApp number with country code.
  3. Add a Photo link if you want. Upload the photo in Content → Files and copy the link.
  4. Write the First message. This is filled in for the shopper.
  5. Click Save.

3.2 Agent settings

  • Active: turn the agent on or off.
  • Name: up to 60 characters.
  • Role: up to 60 characters.
  • WhatsApp number: with country code.
  • Photo link (optional): a link to the photo.
  • First message: up to 500 characters. You can use {page_url}, {product_title} and {shop_name}.
  • This agent has their own hours: the agent uses their own business hours.

Use the arrow buttons to change the order. Use the delete button to remove an agent.

Tip The chat widget needs at least one active agent with a WhatsApp number.
