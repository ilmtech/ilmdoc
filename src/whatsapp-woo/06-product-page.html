Product page buttons

6.1 Order on WhatsApp

This button lets a shopper send you a product order in one click. The message has the chosen variation, quantity and price at the moment of the click.

  • Show an Order on WhatsApp button: turns the button on or off.
  • WhatsApp number for orders: leave it empty to use the first agent.
  • Button text: the text on the button.
  • Message: the text sent with the order.

You can use these codes in the message: {product_title} {variant} {product_reference} {quantity} {price} {product_url} {shop_name}.

6.2 Ask about this product

  • Show an Ask about this product button: turns the button on or off.
  • WhatsApp number: leave it empty to use the first agent.
  • Button text: the text on the button.
  • Message: the text sent with the question.
  • Only for products in these categories: empty means every product.
  • Show the icon: shows or hides the icon on the button.
  • CSS classes (optional, replaces the built-in style): your own style classes.

6.3 Share on WhatsApp

The shopper chooses the contact. The message has the product name and link.

  • Show a Share on WhatsApp button: turns the button on or off.
  • Button text: the text on the button.
  • Add the short description: adds the product short description to the message.
  • Only for products in these categories: empty means every product.
  • Show the icon: shows or hides the icon on the button.
  • CSS classes (optional): your own style classes.

6.4 Subscribe for updates

  • Show a Subscribe button: turns the button on or off.
  • The button opens: A chat with your number, or A link (WhatsApp channel or group invite).
  • WhatsApp number: leave it empty to use the first agent.
  • Link: the channel or group link, used when the button opens a link.
  • Button text: the text on the button.
  • Message: the text sent with the subscribe.
  • Only for products in these categories: empty means every product.
  • Show the icon: shows or hides the icon on the button.
  • CSS classes (optional): your own style classes.
