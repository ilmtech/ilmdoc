Install and open the settings

1.1 Install the plugin

Download the plugin zip file from ilmtech.in. Then upload it to your site.

  1. In your WordPress admin, go to Plugins > Add New.
  2. Click Upload Plugin.
  3. Choose the zip file and click Install Now.
  4. Click Activate.

WooCommerce must be installed and active. The plugin needs it to work.

This plugin is not affiliated with or endorsed by WhatsApp or Meta.

1.2 Open the settings page

After activation, go to WooCommerce > WhatsApp Chat & Order. This is where all the settings live.

The page has tabs across the top: Chat widget, Agents, Business hours, Display rules, Product page, Cart order and Statistics. On the right you see a live preview. You can switch it between Computer and Phone, and tick Chat window open to see the panel.

When you change something, click Save at the top of the page.
