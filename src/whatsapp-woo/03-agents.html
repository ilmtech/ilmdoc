Agents

3.1 What an agent is

Each agent is one WhatsApp number in the chat window. You can add several agents, for example Support and Sales. Drag the handle to change their order.

3.2 Add an agent

  1. Open the Agents tab.
  2. Click Add an agent.
  3. Fill in the fields.
  4. Click Save.
  • Name: the agent name, up to 60 characters.
  • Role: a short role, up to 60 characters.
  • WhatsApp number: in international format with the country code, for example +44 7700 900123.
  • Photo address (optional, https://): a link to the agent photo.
  • Pre-filled message: the text that is ready in the chat when a shopper writes to this agent.
  • Own working hours (otherwise the business hours): tick this to give the agent their own hours. Leave a day empty when the agent is off.

Use Enable or Disable on each agent to turn it on or off. Use the arrows to move an agent up or down, or Remove to delete it.

3.3 Message variables

You can put these codes in a message. They are replaced with real values when the shopper clicks.

  • {page_url}: the address of the page the shopper is on.
  • {product_title}: the product name.
  • {product_url}: the product link.
  • {price}: the price.
  • {shop_name}: your shop name.
