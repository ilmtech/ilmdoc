Install and open the module

1.1 Install the module

The module is free. There is no licence key. Download the zip from ilmtech.in.

  1. Go to Modules > Module Manager.
  2. Click Upload a module.
  3. Choose the module zip file and upload it.
  4. Click Configure when the module is installed.

1.2 The settings page

The settings page has tabs at the top: Chat widget, Agents, Business hours, Display rules, Product page, Cart order and Statistics.

Settings are saved per shop. If you run more than one shop, set up each shop on its own.

Click Save to keep your changes.

Tip The Live preview on the right shows your changes before you save. Switch between Computer and Phone to see both views.

1.3 Texts in your languages

If your shop has more than one language, use the Texts in list at the top. Pick a language, then type the texts for that language.
